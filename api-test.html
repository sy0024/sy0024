这些路径来自 hongguoTV 项目的接口调研记录，是非官方、未经保证的实现线索，不是红果公开 API 文档。H5 不会直接请求这些上游地址。

为什么不让浏览器直连？调研记录指出 App 搜索和视频模型请求依赖客户端签名及设备参数；播放资源还有额外解析 / 加密处理。直接从 H5 发普通 fetch 不能替代这些流程，浏览器跨域策略也可能拦截请求。这里不实现签名模拟或加密绕过。使用下方 bridge API 测试即可验证 H5 对接链路。
